# Schema, copy and export

- Schema tab: column types (physical and logical), nesting, row groups, compression, page index and key-value metadata. Copy schema as JSON puts the schema on the clipboard.
- Copy: the selected cells, or the rows on screen, as CSV, JSON or a Markdown table. Ctrl+C (Cmd+C) copies tab-separated text.
- Export: every row of the current view, with your filters and sort, to a CSV or JSON Lines file.
